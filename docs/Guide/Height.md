> [!info] Part of the [[Guide/Overview|Human Generator Guide]]

Change the height of the character by changing the values of this slider. The rig will be automatically updated once you let go of the slider. Want a random height? Use the randomize button next to the slider. It's also possible to type in values outside of the 150cm to 200cm range.
![[Screenshot_Blender_000168.mp4]]

>[!note] Imperial units
>The slider's values are in centimeters, but above the slider you can see the height in feet and inches.
