## What is a content pack?
Content packs are ZIP files that contain content for Human Generator. They are renamed to have the `.hgpack` extension to prevent automatic unzipping by Safari. When you installed Human Generator, you downloaded and installed the base content as content packs.

## How to save your content as a pack:

>[!warning] 
>*Important:* Since the content pack saving screen is still relatively new, it's recommended to make a backup of the folder you installed Human Generator in! So far the operator has always worked, but it's better to be prepared for the worst in case something goes wrong.

#### 1) Go to the Content Packs tab of the Human Generator preferences:
![[cpacks1.mp4]]

---

#### 2) Enter a name for your pack, and press Create!
*Important:* Currently it's not possible to change the name of your pack without manually editing .json files, so pick the name carefully if you don't want to dig into the file structure of HG.
![[cpacks2.mp4]]

---

#### 3) Select the content that should be part of this pack, enter your name and a website/social media URL.
![[cpacks3.mp4]]

---

#### 4) Select a folder where the pack will be saved, and press Export and Save:
![[cpacks4.mp4]]

A `.hgpack` file is now added to the folder you selected!

### Want to edit the pack?

You can always edit a pack later on, and re-export, by selecting the pencil icon next to the content pack.
