# Adding custom content
Human Generator allows you to extent the default content with new contant you or others have made. This guide shows you how to create custom content, how to save it to the HG library and finally how to share your content as a content pack!

>[!warning] 
>The options shown in this menu are for the **actively selected** human. Make sure the correct human is active to prevent unintended changes. When multiple humans are selected, only the active one is used for the custom content screen.


![[Screenshot_Blender_000202.webp]]
1. **Adding clothing to a human**: This is one of two steps for adding clothing to HG. See [[Custom clothing]].
2. **Documentation button**: Each category has a shortcut to the documentation page.
3. **Refresh button**: By default, HG only shows the categories where it has detected that you've made changes or added something. If for example a newly created shape key is not in the list, press refresh.
4. **Show all button**: If you've made changes but the add-on does not detect it, even after refreshing (3), click here to see all categories.
5. **Content categories**: Here the add-on will show categories it has detected custom content. By default "Human" and "Diffuse texture" are always visible. Below every newly created shape key will show. **NOTE:** It is not possible to make changes to existing shape keys and overwrite them, you can only create shape keys with new names.
6. **Save button**: Click here to start the saving process for this type of content. See the individual guides for more information:
	1. [[Custom clothing]]
	2. [[Custom pose]]
	3. [[Custom hairstyle]]
	4. [[Custom shape keys]]
	5. [[Custom texture sets]]
	6. [[Custom starting humans]]
7. **Managing content packs**. You can share the content as a content pack. For more info see [[Exporting your content as a pack]]

>[!note] More types of custom content
